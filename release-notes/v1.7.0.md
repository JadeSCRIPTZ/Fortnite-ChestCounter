**English** · Download **`ChestCounter.exe`** below, run it, follow the short setup. Nothing to install. Already using it? Your history and settings are kept.

> **Turn on replays in Fortnite first**: *Settings → Game → Replays → Record Replays: On*. The tool only reads these replay files: no game modification, no access to the game's memory. **No network access unless you turn on the update check** (this version also keeps the treasure pictures inside the exe).

**What's new in 1.7.0**
- **Merged with Chest Counter 1.5.1 by LED-N** (code reviewed before merging): the counter now opens in its **own window** (Home, Report, Overlay, Settings, Help) instead of the console
- **Your chances**: the weekly treasure chances explained clearly (a word for each chance, never 100%), this week's items with their picture, countdowns to the next Treasure Hour, and notices
- **Settings**: times in local time or UTC, 12- or 24-hour clock; chests added by hand (the pencil) are listed and can be undone; the overlay keeps the last match while the next one is played
- **Counting fixed**: closed chests you break without touching them are counted again. Replays still on your PC are analyzed again
- **Kept from this fork**: match detail with the other players, by season, by mode, who you play with, player search, loot rarity, `players.csv`
- **Safer**: links in the window open only as web addresses and the window never leaves its own page; a notice can no longer run code; the uninstaller only deletes the counter's own folder

Windows may show *"Windows protected your PC"* (unsigned exe): *More info → Run anyway*.
