First release of the hardened fork of LED-N/Fortnite-ChestCounter v1.3.0 (reviewed at commit daba16d).

- Counts the chests you open or destroy in Fortnite, from your replay files, with an in-game overlay and an HTML report.
- Does not touch the game process, memory or your Epic account.
- Update check is off by default; the updater only accepts files from this repository's releases and refuses a release with no SHA-256.
- Build without third-party GitHub Actions.
